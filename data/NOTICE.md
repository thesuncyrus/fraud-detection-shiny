# Dataset attribution

Dataset reference: Financial Transactions Dataset: Analytics, published by ComputingVictor on Kaggle and credited on its data card to Caixabank Tech for the 2024 AI Hackathon.

Source: https://www.kaggle.com/datasets/computingvictor/transactions-fraud-datasets

The upstream data card specifies Apache License 2.0. A copy is provided in LICENSE.txt. This notice applies to the data, not a blanket license over collaborative project code. The team’s derivative analysis files join source tables, balance the outcome classes, standardize monetary/category fields and aggregate customer attributes.
